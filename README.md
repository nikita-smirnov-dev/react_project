# React Project

Учебный проект, демонстрирующий навыки работы с React.

## Технологии
- React
- JavaScript
- TypeScript
- CSS


### Установка зависимостей

```bash
npm install
# или
yarn install
```

### Запуск в режиме разработки

```bash
npm run dev
# или
yarn start
```


## Функциональность
- Просмотр каталога фильмов
- Поиск фильмов по названию
- Добавление фильмов в избранное
- Просмотр трейлеров
- Адаптивный дизайн
- Рейтинг фильма
- Детальная информация о фильмах

Приложение откроется по адресу [http://localhost:5173](http://localhost:5173)

### Сборка для продакшена

```bash
npm run build
# или
yarn build
```

Приложение использует [The Movie Database API](https://cinemaguide.skillbox.cc/) для получения данных о фильмах.
